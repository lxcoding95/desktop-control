# Code of Conduct

We want a technically rigorous, inclusive and respectful open-source community.

Participants must:
- Engage professionally, offer constructive criticism and avoid personal attacks.
- Respect contributors' identities, experience and privacy.
- Avoid harassment, hateful language, threats, doxxing and unsolicited exposure of private data.
- Keep vulnerability details in private security channels.

Maintainers may moderate repository discussions, close abusive contributions, and restrict access to protect participants. Enforcement decisions should be documented privately where sensitive details are involved.

To report conduct concerns, contact repository maintainers through available GitHub account communication channels. Do not send security exploits through conduct reports: use [SECURITY.md](SECURITY.md). A dedicated confidential conduct-report channel is **not yet established** and remains a governance gap before broad community launch.

This is an initial project policy, not an assertion that a separate moderation team exists.
